## Git commits
- Never add a "Co-authored-by:" trailer, "Generated with Codebuff" line, or any other AI or tool attribution to commit messages, pull request descriptions, or code comments.
- Commit messages contain only a short summary line and, if needed, a plain description of the change.
- The only author of every commit is the user's own git identity. Do not change git config user.name or user.email.
- Never use --no-verify or otherwise skip git hooks.
