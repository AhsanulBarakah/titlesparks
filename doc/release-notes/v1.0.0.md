TitleSparks attaches a visual marker to the titles of the posts you choose — an
icon, an image, or an animated GIF — and lets that marker change on a schedule.
Each post carries a timeline of up to three stages, and each stage has its own
asset, position and expiry, so a "New" badge can hand over to a quieter icon and
then disappear without anyone editing the post again.

One library of assets is shared across the site; every post picks from it and
carries its own timeline. The icon follows the title wherever that title is
printed — the post itself, an archive card, a sidebar's latest-posts list, and
the previous and next links that point at it.

A WordPress plugin, for WordPress 6.6+ and PHP 7.4+. Download `titlesparks.zip`
and install it from **Plugins → Add New → Upload Plugin**.
